# Obsidian 链接语法参考

## 笔记链接
| 语法 | 效果 |
|------|------|
| `[[文件名]]` | 链接到笔记 |
| `[[文件名\|显示文本]]` | 带自定义显示文本的链接 |
| `[[文件名#标题]]` | 链接到笔记内的特定标题 |
| `[[文件名#^块ID]]` | 链接到特定块 |

## 嵌入内容
| 语法 | 效果 |
|------|------|
| `![[文件名]]` | 嵌入笔记全文 |
| `![[文件名#标题]]` | 嵌入笔记中的某一节 |
| `![[文件.pdf#page=3]]` | 嵌入 PDF 第 3 页 |
| `![[图片.png]]` | 嵌入图片 |

## /connect skill 追加格式

### 关联标准（严格）

只有满足以下任一条件的笔记才可作为关联：
1. **前置依赖**：A 是理解 B 的必要前置知识（如"向量空间"→"线性变换"）
2. **后续推广**：A 是 B 的直接推广或特化（如"夹逼定理"→"积分定义"）
3. **等价表述**：A 和 B 描述同一概念的不同形式（如"极坐标"↔"复数极性式"）

**不得关联的情况：**
- 仅共享某个运算或术语（如"链式法则"和"复数乘法"都涉及乘法）
- 仅属于同一学科或同一章节
- 仅在证明中使用了相同的技巧但概念无关

### 写入格式

在笔记末尾追加（如已有该节则更新）：
```markdown

---
## 相关笔记
- [[文件名]] — 关联原因（不超过20字）
- [[文件名]] — 关联原因（不超过20字）
```

写入时使用：
```
C:\Users\bwica\AppData\Local\Programs\Python\Python313\python.exe C:\claude\scripts\connect_note.py --note "<笔记路径>" --link "文件名|关联原因"
```

## 注意事项
- 文件名**不需要**写 `.md` 扩展名
- 路径中有空格不需要转义，Obsidian 自动解析
- 链接在 Obsidian 内可点击跳转；在 Claude 中仅作文本标识
- 文件名大小写不敏感（Windows vault）
