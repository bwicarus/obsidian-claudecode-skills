# Obsidian 链接语法参考

## 笔记链接
| 语法 | 效果 |
|------|------|
| `[[文件名]]` | 链接到笔记 |
| `[[文件名\|显示文本]]` | 带自定义显示文本的链接 |
| `[[文件名#标题]]` | 链接到笔记内的特定标题 |
| `[[文件名#^块ID]]` | 链接到特定块 |

## 嵌入内容
| 语法 | 效果 |
|------|------|
| `![[文件名]]` | 嵌入笔记全文 |
| `![[文件名#标题]]` | 嵌入笔记中的某一节 |
| `![[文件.pdf#page=3]]` | 嵌入 PDF 第 3 页 |
| `![[图片.png]]` | 嵌入图片 |

## /connect skill 追加格式
在笔记末尾追加（如已有该节则更新）：
```markdown

---
## 相关笔记
- [[文件名]] — 关联原因（不超过20字）
- [[文件名]] — 关联原因（不超过20字）
```

## 注意事项
- 文件名**不需要**写 `.md` 扩展名
- 路径中有空格不需要转义，Obsidian 自动解析
- 链接在 Obsidian 内可点击跳转；在 Claude 中仅作文本标识
- 文件名大小写不敏感（Windows vault）
