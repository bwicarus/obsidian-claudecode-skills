## 一、你可以直接上手试的

### 1. 「第 3 块 + 这句话」钉卡片（你定的寻址方式）

书里现在每页正文长这样：

```
[01] 熱力学の第一法則は…
[02] エネルギーは保存される…
```

跟 AI 说「把第 2 块那句能量守恒钉成卡片」，它发的是：

```json
{"kind":"page-chars", "page":12, "block":2, "text":"エネルギーは保存される"}
```

**不用先调工具，也不用算序号。** 块把搜索范围锁住，所以同一句话在页内重复
出现也不会认错。

四个表面都通了：普通书页、漫画/表格页、网页、（插入页见下）。

回执里的 `how` 就是这次定位的质量：
- `exact` 用了序号
- `by-block` 在你指的块里找到
- `by-text` 没给块号，全页找
- `by-text-block-missed` **给了块号但没在块里** —— 块对不上了，这条是有意
  加的，静默降级在这条链上最难查

### 2. 自建页的位置标签

角标从「📝 我的页」变成「📝 46-a」。同一位置建第二张是 46-b。

⚠ 它是**显示标签不是页码**。跟 AI 说「46-a 那页」它认；但它不会进
`bind.page` / `?page=` / 搜索索引 —— `parseInt("46-a") === 46` 会把它静默
当成真实的第 46 页。

### 3. AI 终于能读全 / 改 / 删自建页

- **读**：你手打的 markdown 正文此前**一个字都读不到**（只认 blocks），
  现在能读了。钉在那页上的卡片/便签也不再被绕过。
- **改 / 删**：`userpage_list` / `userpage_edit` / `userpage_delete`。
  试试跟 AI 说「列一下我建过哪些页」「把 46-a 那页标题改成 X」「删掉 46-a」。
- **删得掉也撤得回**：删除会出一张撤销卡。此前 AI 造纸是不可逆写操作。

### 4. 网页上的加卡片 / 锁定元素

真机验证过：真三击选段、真 Ctrl+A、纯 div 站点（X/Gmail 那类）、
振假名开着、译页开着 —— 都不会把已钉的卡弄错位。

## 四、今晚踩到、值得记住的

- **`_upage_read_text` 只认 blocks** —— 你在插入页写的字 AI 一个都看不到。
  这条是"AI 没有读取手段"里最实际的一半。
- **工具注册表是 fail-closed 的**：新工具只注册进 `TOOLS` 而不登记命名空间
  映射，整个 assistant 模块 **import 就失败**。这个闸设计得好。
  顺带撞到第二道：每命名空间上限 9 个 —— 自建页三工具因此另开了 `userpages`。
- **用 segments 拼正文会把整页缩成摘要**：每条 segment 的 text 是截断到 120 字的
  预览。既有那条 `text.length === 1500` 的断言抓到了它 —— 它钉的是
  "整页真文本"这个不变量而不是某种写法，所以抓得住。
- **`parseInt(x) || 0` 在"字段可选"之后是陷阱**：把"没给"变成 0，于是消歧时
  偏向页首那一处，而且看不出它是猜的。
