## 1. 注意力画像(地基,2026-07-17)

**做什么**:把你所有学习行为汇成一个"当前在学什么"的加权画像,可输出任意时间段的焦点词。

- **7 个渠道**(各有权重):查词 lookup(1)/高亮 highlight(3)/问 AI qa(2)/自测 check(4)/读页 read(0.5)/新建笔记 note(5)/Anki 答错 anki_lapse(2)。
- **零侵入导入**:不在 webapp 埋点,各渠道本来就有持久层(查词日志/高亮 sidecar/对话归档/检查报告),每 15min 增量扫进 `events.db`;原始账本 `raw-events.jsonl` 只增不删(重建能力保险)。
- **双半衰期衰减**(短 7d + 长 90d)× IDF:近期热 + 长期兴趣融合,通用词自动降权。
- **实测**:2374 事件,焦点榜真实反映在学内容。**重要发现**:91% 是语言书查词(料理师/応用情報/EGIU/Feynman),LADR 等数学书在阅读器上几乎零参与(数学在 Anki 学)。

**代码**:`scripts/attention_profile.py`(单文件引擎)+ `state/attention/`(events.db / raw-events.jsonl / concepts.json / emb-cache.npz / fusion-weights.json)。工具 `learning_focus`。

## 2. 跨语言概念归一

**做什么**:书是英/日原文、你用中文问,系统把它们认成同一概念。

- **两层归一**:L1 字形(NFKC+日本新字体+繁简)+ L2 语义(concepts.json 别名表)。
- **融合打分找关联**:四信号(时间共现 NPMI / 向量余弦 / 词部件重合 / 词典)几何加权 > 阈值 → 交 AI 判定。
- **权重反向学习**(点睛):拿 100% 确认的词典对应当金标准,逻辑回归反推四信号权重(hold-out F1=1.0),把拍脑袋的权重变成数据学的。

**代码**:`attention_profile.py` 的 `norm_key/fuse_score/fit_weights/build_concepts`,daily 步「跨语言概念归一/融合权重学习」。

## 3. 材料寻址 + 诊断链

**做什么**:把"焦点词"和"具体材料"画等号,并能顺链条任意穿越。

- **统一地址 material ref**:`book:<文件>#p<页>` / `note:<vault相对路径>` / `anki:<cid>` / `check:<文件>` / `kg:<书>#<节点>`。
- **relate_material**:焦点词 → 你**实际关注过**的材料,按相关度排序(半衰期 60d 长记忆:半年前学的高相关材料照样找到)。
- **read_material**:读任意一层内容(书页原文/笔记全文/卡片正反面/KG 节点)。
- **material_graph**:从任意位置、任意方向、任意深度 BFS 展开诊断链——卡↔源笔记↔书页↔KG 节点↔前置根源。
- **诊断链打通**:一张答错的 Anki 卡 → 源笔记 → 书页 → KG 节点 → 前置。制卡时埋 `<!--@src-->` 让来源可秒提取。

**代码**:`attention_profile.py` 的 `relate_material/read_material/material_graph/material_neighbors/obsidian_to_ref`;工具 `relate_material/read_material/material_graph`。

## 4. 学习近况(困难档案状态机)

**做什么**:自动记录"你最近卡住的知识点",在你自然问到相关内容时,AI 结合它给建议。**AI 全程不做实时判断**(不增负担/不干扰回答),只在生成时后台分析一次 + 对话中被动响应。

**五步生命周期**:
1. **触发**(daily,行为信号,不用 AI):Anki 同知识点窗内答错≥3(按 KG 节点聚合)/ 自测正确率<50%。
2. **分析**(daily,AI 后台一次):顺 material_graph 找前置根源 → 补"怀疑 + 建议"。
3. **注入**(每轮对话):双路 = 最近 N 条 active(recency)+ 当前阅读语境关键词检索 K 条(relevance),清单式进系统提示。
4. **响应**:别主动打断,你自然问到相关内容才结合(提议做卷/反问定义/出题)。
5. **消解**(daily):连对≥2→resolved / 30 天没动静→archived。

- **状态**:active(注入)/ resolved(解决,留档)/ archived(不学了,留档)。**只转状态 + 留档,永不删除**(复发从 resolved 拉回 active)。
- **消解第四条**:工具 `situation_feedback(concept, kind)`——对话中你明确表态(懂了→resolved / 别提了→archived / 还是不会→强化)。

**代码**:`scripts/learning_situations.py`;assistant 注入 + `situation_feedback` 工具;daily 步「学习近况」。
**修过的严重 bug**:SQLite `HAVING lapses` 撞 cards 表同名列(全历史累计),触发信号一度用错列;已改 COUNT + Python 侧按知识点聚合。

## 5. 学习闭环:诊断卷 → 掌握度 → 遗忘回访

### ① 分层诊断卷(1a–1d 全链)

- **1a 判分双模**:选择题**可点选** → 客观比对(`picked==answer`,不烧 AI);没点选而**手写** → 回退现有 AI 画面识别。每题挂 `node_id`/`layer`,判分结果按知识点聚合。
- **1b 前端可点选**:阅读器诊断纸的选项可点(选中高亮),picks 随检查载荷到后端(不烧 AI)。
- **1c make_diagnostic**:给一个知识点 → material_graph 找 prereq 链 → AI 沿链**分层出选择题**(前置题 + 目标题,每题挂节点)→ 插一张诊断纸。诊断逻辑:前置错=根源在前置;前置对+目标错=目标本身没吃透。
- **1d 掌握度提案**:判分后按知识点聚合 → `mastery_proposal` 出提案 → 你确认 → `apply_mastery` 写 override + 消解相关近况。

**怎么用**:阅读器里对助手说"考考我子空间"/"我到底哪没掌握",它调 make_diagnostic 插诊断卷;点选作答、检查;问"结果怎样"给提案;你说"确认"才改 KG。
**代码**:`assistant.py`(make_diagnostic / mastery_proposal / apply_mastery / _gen_choice_question / _objective_grade / _attach_nodes)、`task_runtime.py`(_check_page 判分分流 + node_results)。

### ② 掌握度 override 层

**做什么**:把诊断/确认的掌握度写进一个外挂层,daily 重算不覆盖、可溯源、可撤销。
- 铁律:**AI 提候选,绝不自动改**(错误有成本)。
- `link_and_mastery` 在状态计算**前**注入 override mastery → 解锁沿 prereq DAG 自然传播。
**代码**:`scripts/kg/mastery_overrides.py`;`state/kg-mastery-overrides.json`。

### ③ 遗忘回访

**做什么**:resolved 不是终点。困难卡在 Anki 里到期(借 Anki 自排的 ivl,不自算 FSRS)+ 距解决≥7天 → 拉回 active(trigger=revisit + "还记得吗"),你确认记得又回 resolved。
**代码**:`learning_situations.py` 的 `detect_revisits`,进 daily。

## 6. 元画像(错误模式聚合)

**做什么**:比学习近况高一层。近况是"卡在**这个点**",元画像是"你有**这类**系统性弱点"。
- 样本 = 学习近况(带卡面样例)+ 诊断报告未全对的知识点。
- AI 归纳 2-4 个元认知弱点模式(name + 证据 + 学习策略)。**实测**:从 4 个线代困难归纳出"抽象概念具象化困难""概念间逻辑链条断裂",各带可执行策略。
- **不强注入**(元层信息宏观,做噪声);工具 `error_patterns()` 按需查。
**代码**:`scripts/error_meta_profile.py`;daily 步「错误模式元画像」。

## B. 算法细节(公式)

### B.1 焦点画像(rebuild_profile)
```
score(term) = (α·S_short + (1-α)·S_long) × IDF_books
S_h = Σ_events  w_渠道 · sat · 2^(−Δt_days / half_h)
```
- 渠道权重 `W = {note:5, check:4, highlight:3, qa:2, lookup:1, read:0.5, anki_lapse:2}`
- 双半衰期:短 `half_short=7d`、长 `half_long=90d`;`α=0.65`(短期占比)
- **BM25 廉价饱和** `sat = 1/(1+0.3·(n−1))`(同词同日第 n 次贡献,防单日刷量)
- **事件内稀释** `1/√N`(一条事件抽 N 个术语,防单条长事件淹没几千条查词)
- **IDF** = 按「出现过的不同书数」算(跨书泛词自动降权,比人工停用词表自适应)
- 时间窗查询 focus_window:窗内**不做**时间衰减(窗口本身即时间选择),纯 `w/√N × IDF`

### B.2 材料检索(relate_material)
```
rel(material) = Σ_events  chw · (0.4 + 0.6 · 2^(−Δt_days/60))
```
半衰期 **60d**(比焦点 7d 长得多:相关性主导、长记忆),0.4 底权重=久远材料保 40%(时间是加分不是门槛)。渠道权重 `_MATERIAL_CH_W={note:5,check:4,highlight:3,anki_lapse:2.5,qa:2,tool:1.5,read:1,lookup:1}`。

### B.3 跨语言融合打分(fuse_score)
四信号,几何加权平均:
```
P(A,B 同概念) = [ ∏_{i∈{T,S,O,D}} (ε + w_i · s_i) ]^(1/4)
```
- **T** 时间共现:同一天在「书」和「我的笔记/提问」都出现 → NPMI 式(只排序,不单独判定)
- **S** 向量相似:`max(0,(cos(emb_A,emb_B)−0.5)·2)`(gemini-embedding-001)
- **O** 词部件重合:长词组内的基础词重叠
- **D** 词典:A 是英文 且 B∈ECDICT(A) → 1,否则 0
- 权重 `w_i` **不是手调**,是 fit_weights 学出来的(见 B.4)

### B.4 权重反向学习(fit_weights,用户点睛)
- 逻辑回归 `P=σ(w·[T,S,O,D]+b)`,numpy 梯度下降(4 维,秒级),**权重非负**(几何平均语义)。
- **金标准免费**(零人工标注):
  - 正例(label=1)= ECDICT 命中 **AND** 向量 cos>0.72(两独立信号双确认)∪ concepts.json 里 AI 判 same 的对
  - 负例(label=0)= 随机配对 ∪ 时间共现>0 但 cos<0.40(feynman↔原子 类高频互撞)
  - ⚠ 正例用「词典 AND 向量」、负例用「共现但向量远」→ 每个信号都有独立正负样本,避免"正例都来自词典→学出 D 最大"的循环论证
- τ 按 F1 最优选。实测 holdout F1=1.0(n_pos=281,n_neg=400)。

### B.5 概念归一三步(build_concepts)
① 候选=词典(ECDICT 释义 ∩ 我的中文术语,高召回)→ ② 排序=时间共现×双边热度 → ③ AI 判词义(gemini 一次批量,**严防过度合并**:包含/上下位/同领域相关一律 false)。结果写 concepts.json,`norm_key` 查表 O(1)(热路径不调 AI)。

### B.6 KG 掌握度计算(link_and_mastery)
- **叶子 L2 mastery** = containing_notes 里各 record 的 max(status_snapshot.mastery_avg 或 1−weakness)
- **A1 融合**:`mastery = max(Anki 反算, 诊断得分)`(诊断得分=Σcorrect/Σtotal,跨所有检查报告)
- **反向传递**:L2 有效 mastery = max(自身, 所有 descendant 的 mastery)(能掌握高级=已掌握前置)
- **override**:人工确认值在状态计算**前**注入 mastery,解锁沿 DAG 传播,daily 重算不覆盖
- **L0/L1** = 子节点状态取最强(agg_state)
- **三态(⚠ 见文首「已知问题」#1)**:实际由 `mastery_level` 决定——`level≥2→mastered`,而 `compute_level` 里 `mastery≥0.20→level2`。**即 mastery≥0.20 就被标 mastered**(不是 0.8)。这是既有逻辑的语义虚高,待修。
- **五级 mastery_level**(0-5):0 没碰/未通、1 刚解锁未达门槛、2 达门槛(可作前置)、3-5 中/较好/完全
- **bottleneck_score**:该节点若解锁能连带解锁多少 currently-locked 后继(前端标"卡点")
- **A2 engaged**(独立字段,不进 mastery):`Σ_页 渠道权重·次数`(note/highlight/qa/check 强、lookup/read 弱),按本书最活跃节点归一到 0-1
- **E diag_suspect**:前置通过率≥0.7 但目标≤0.4(都测过≥2次)→ 标可疑 prereq 边

### B.7 学习近况阈值
触发:同 KG 节点窗内(45d)Anki 答错≥3 / 检查正确率<50%。消解:困难卡最近连对≥2→resolved / 30d 无动静→archived。遗忘回访:resolved 卡在 Anki 到期(now > 上次复习 + ivl 天)且距解决≥7d → 拉回 active。
