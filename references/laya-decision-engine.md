# Laya 定型判断引擎 —— 装在哪、能干什么、**不能**干什么

2026-09-23 实测。装在 Windows 服务器侧（`C:\claude\laya-venv`），常驻服务
`scripts/laya_decide.py --server`，协议与 `spacy_parse.py --server` 逐字同构
（stdin 每行一个 JSON、预加载、先回 `{"ready":true}`），便于共用调用方的
锁/超时自愈那套。

Laya（convaiinnovations/laya）对任意 state 回答 **choice / score / noul** 三类
定型问题，不生成文本 → 没有解析和幻觉；概率经 RLCD 校准，可按阈值自动放行。

## ⚠ 先读这条：英文可用，中文不可用

同一篇「商空间」笔记、同样 10 个候选概念，只换语言：

| 概念 | 英文（laya/ModernBERT-large） | 中文（multilingual/mmBERT-base） |
|---|---|---|
| quotient space（真·主题） | **0.850** | 0.586 |
| dimension formula | 0.743 | 0.910 |
| coset | 0.552 | 0.718 |
| subspace | 0.651 | 0.674 |
| inner product space（**不在文中**） | 0.086 | **0.738** |
| eigenvalue（不在文中） | 0.077 | **0.565** |
| dual space（不在文中） | 0.207 | **0.790** |
| null space（不在文中） | 0.137 | **0.908** |
| determinant（不在文中） | 0.115 | **0.778** |
| Jordan form（不在文中） | 0.066 | 0.036 |

英文：相关项全 ≥0.55、无关项全 ≤0.21，中间有干净空档（阈值 0.35 即可）。
中文：**无关概念压过真正的主题**，接近噪声 —— 与它自己 benchmark 里
multilingual 的 MASSIVE 0.451 对得上（那个数字本来就只是"能用"级别）。

⚠ 所以 **vault 里中日文为主的判断不要交给它**。想用就得先把判断对象换成英文
（比如用节点的英文名/英文摘要），而那本身要另花代价。

## ⚠ 第二条：严格判据它做不了

「这段文字是否给出了完整的形式定义」——
文中明写 `We define the quotient space V/U ...`，它只给 **0.213**。
而「是否含证明或例子」判得很准（0.870 vs 0.080）。

也就是说它擅长**存在性/相关性**这类判断，不擅长**是否满足某条严格定义要件**。
KG 关联那条判据（完整定义 + 展开，几百候选里命中 0~3 个）**两条都踩中**：
判据严格 + 内容中文。所以那条链**不适合**交给它，硬上会悄悄丢召回，
而丢了什么没有地方看得见（见 `evidence-quality-lessons.md`）。

## 实测性能（RTX 4090 Laptop 16GB，float32，cuda:0）

| 问数/次 | 总耗时 | 每问 |
|---|---|---|
| 1 | 124.3 ms | 124.3 ms |
| 10 | 131.7 ms | 13.2 ms |
| 25 | 135.8 ms | 5.4 ms |
| 50 | 151.8 ms | 3.0 ms |
| 100 | 248.2 ms | **2.5 ms** |

**约 120 ms 是固定开销**（不是算力）：单问比它宣称的 T4 39.5 ms 还慢 3 倍，
批量却比 T4 快（100 问 2.5 ms/问 vs T4 的 15.9）。结论：**必须批量用**，
一次 50–100 问是甜点；单问调用没有意义。

首次加载约 158 s（含下载检查点），之后预载常驻约 4 s。三个检查点全预载
显存占用约 1 GB。

## 装它时踩的坑

- Windows 上 `huggingface_hub` 默认用符号链接，非管理员会
  `OSError: [WinError 1314] 客户端没有所需的特权`。它自己能探测并退化成复制模式，
  但**首次可能在探测热起来之前就炸**。重跑一次即可；要消警告设
  `HF_HUB_DISABLE_SYMLINKS_WARNING=1`。不必开 Windows 开发者模式。
- 默认 PyPI 的 Windows torch 轮子只有 118 MB = **纯 CPU**。要吃 GPU 必须走
  `--index-url https://download.pytorch.org/whl/cu130`（2.14.0 的 win/cp313
  有 cu126 / cu130 / cu132 三个）。装完约 3 GB。

## 结论：现在该用在哪

按上面两条约束筛下来，适合的是**英文内容 + 存在性/相关性/程度**这类判断：

- 英语语法分析（`grammar-nodes.json` 那套，内容本来就是英文）
- 生词系统的英文判断
- 英文卡片的质量体检（答案过长/多知识点/指代不清 → `score` + `noul`）
- 它自带的 guardrails / moderation 预设（如果将来需要）

**不适合**：KG 关联判定、中文笔记的任何判断、需要"是否满足严格定义"的判据。
