# Vault 学科分类体系

Vault 根目录：Linux 实例（当前主实例）`/home/bwicarus/obsidian`；Windows 实例 `C:\obsidian\`

## 一级科目与二级分支

### 数学
- 微积分（极限、导数、积分、级数、无穷小）
- 线性代数（矩阵、向量空间、线性变换、行列式、特征值）
- 离散数学（图论、集合论、逻辑、组合数学）
- 概率与统计

### 物理
- 力学（运动学、动力学、能量、动量）
- 电磁学（电场、磁场、电路）
- 热力学（温度、熵、热力学定律）
- 光学（几何光学、波动光学、色散）
- 近代物理

### 计算机科学
- 编程语言（C语言、Python、语法、标准库）
- 数据结构与算法（排序、查找、树、图算法）
- 计算机网络（TCP/IP、DNS、HTTP、协议栈）
- 操作系统（进程、内存、文件系统）
- 计算机组成原理（CPU、内存、指令集、编码）
- 软件工程（设计模式、项目管理、开发方法）

### 英语
- 语法
- 词汇
- 写作与表达

### 日语
- 语法
- 词汇
- 汉字（漢字）
- 听说

## 分类原则
1. 按笔记**内容**归类，不强制按所在文件夹归类
2. 跨学科笔记放入最主要的科目
3. 无法判断的放入对应科目的 `### 其他` 节
