# emergent 概念网算法(定稿 v3)—— 阅读时生长 + 笔记为骨骼 + AI 审计代替人工确认

> 用户三轮定调收敛:① 彻底抛弃预建骨架,节点/边从阅读涌现;② 算法做全部预选/组装,AI 只在有界节点上判断;
> ③ **主流程=阅读时生长**(注意力新词→向前搜索→相关性→AI 定关系→建/更卡),不依赖书有规整定义句;
> ④ **Obsidian 笔记为骨骼**(概念=笔记,边=wikilink 镜像,挂起边=未解析链接);
> ⑤ **人工逐条确认废除**,改后台 AI 定期审计(掌握度铁律不受影响,仍须用户确认)。

## 0. 分工总原则

| 环节 | 谁 |
|---|---|
| 注意力发现新词、vocab 路由、向前搜索、摘句段、相关性 top-k、查卡、建/更笔记、挂起边、防环 | **纯算法** |
| ①对算法给的 (主体词, top-k 相关词) 按原句分类关系;②从首现前后文提取定义(找不到才生成,打标) | **AI(有界)** |
| 定期审计边(重读证据,降级/摘除站不住的) | **AI(后台)** |
| 随手纠错(可选)、掌握度确认(必须) | **用户** |

## 1. 主流程:阅读时生长(任何书通用)

触发:注意力榜新词达标(score top-N 且 n7≥3 或 burst≥3;≥2 事件跨 ≥2 渠道含 ≥1 深渠道)。

1. **vocab 门**(先决):`nk in vocab OR 原surface in vocab` → 语言项去 vocab,终止。**修 2 bug**:
   繁简不对称(norm_key('議事')='议事' vs vocab 存原形)必须双查;`_vocab_set()` 空集必须 **fail-closed**。
   碎片门(公衆⊂公衆衛生 丢)+ 概念正信号门(in_kg / KG 节点名 / 已有概念笔记;不用 domain-terms 当门)。
2. **向前搜索**:在 pdf-search.db 该书 `pages_data.body` 搜第 1 页~**当前阅读位置**(reader-positions)的该词
   全部出现 → 摘出所在**句子+段落**。"向前"天然偏向前置侧(教科书先讲前置)= 免费方向信号。
3. **相关性(纯算法)**:统计句段内其它词(过 vocab/停用词),权重=同句(×2)>同段 ×频次×IDF → **top-k(k≤5)**。
4. **AI ①关系分类**(一次调用):给 (主体词, top-k, 各自原句),输出严格 JSON
   `[{term, relation: prereq|related|instance|none, evidence_quote}]`;AI **只能在给定 k 词里选**,
   quote 必须子串校验命中所摘原文,失败该条作废。方向默认:相关词(出现在前文)→ 主体词;AI 只能降级不能反向。
5. **机械查卡分支**:
   - 相关词**已有**概念笔记/节点 → 直接建边(证据=书原句,锚 `book#page`);
   - 相关词**没有**卡 → **不递归新建**,写 wikilink 即成**挂起边**(Obsidian 未解析链接);
     它日后自己攒够注意力走同一流程生成笔记时,链接自动解析、边自动激活(promote 时扫未解析引用它的笔记)。
   - 主体词无卡 → **新建概念笔记**(§2);已有 → 把新关系并进它的「概念链接(自动)」区。
6. **AI ②定义提取**:取该词在书中**最前方 2-3 次出现**的前后文(各 ~500 字)喂 AI:
   "尽量从这些原文里找出定义句**逐字引用**;确实没有才自己写一段,并如实标注 ai_generated"。
   逐字引用做子串校验;AI 生成的定义**永不作为将来抽边的扫描源**(边证据本就锚在书原句,不依赖它)。

## 2. 笔记为骨骼(Obsidian)

- **粒度与命名(用户编号设计)**:一个概念=一篇笔记,`资源/概念/<书名>/<编码>-<概念名>.md`;
  编码=三位十六进制 `<科目><细分><源头>`(如 300-食中毒:3=公衆衛生/0=基础/0=料理師教材),与存量笔记同族
  (000=数学/线代/LADR、010=数学/微积分)。**注册表** `state/attention/note-codes.json` 记录每个编码的
  {科目,细分,源头book_rel},新书首个概念自动分配下一空位、编码永不复用、用户可改名;旧笔记编码登记为 legacy。
  **机器只操控注册表里自己分配的编码 + frontmatter `type: concept-auto` 的笔记**(所有权双标记,不猜前缀)——
  这就是"其他功能只碰特别笔记、不被旧笔记污染"的实现。
- **登记管线防误触**:三位编码命中 NOTE_PATTERN 会被 pending_notes→register→Anki 扫走(污染环),
  故 `pending_notes` 加一行排除 frontmatter `type: concept-auto`;用户**亲手编辑过**(status→user-edited)
  的自动笔记才升格进登记管线("机器写的不算你的笔记,你动过的才算")。
- **wikilink 用别名形式** `[[300-衛生管理|衛生管理]]`(文件名带码、显示干净);挂起边编码可预判(同书同码)。
- **跨书/跨语言同一概念 = 一概念一笔记**(用户定):编号第三位记"出生书";同概念再现于别的书/语言时
  **不建新文件**,而是 aliases 登记 + 定义句按来源分节追加进同一篇(`## 定义(Strang p5)`)。

### 2b. 多语言概念身份(防"vector space"与"向量空间"裂成两篇,用户点名先决)

三道防线(复用既有跨语言归一 L2 体系,接入位置=主流程第 5 步"机械查卡"):
1. **创建时身份解析(主防线)**:查卡按**概念身份**级联——norm_key 精确(同语变体/繁简)→
   concepts.json 身份表(已归并的直接命中)→ 别名反查(笔记 frontmatter `aliases:` + concept-aliases.json)→
   都未中且词为外语/新词 → **建卡前一次有界 AI 判**(候选=同科目/时间邻近的既有笔记概念,问"是否同一概念",
   严格 JSON,结果写进 concepts.json 不重判)。
2. **命中即合并不新建**:同概念 → 既有笔记 frontmatter `aliases:` 加新语言名(Obsidian 原生按别名可搜可链)+
   新来源定义句追加为分节;挂起边 wikilink **先过身份解析**再写(指向 canonical 文件名)。
3. **周期归一兜底自动修复**:AI 判不准 → **宁可缓建**(进"待定身份"队列,夜间 concepts.json 归并批定夺,下轮再建);
   若重复仍漏进(归并发现两篇笔记同一身份)→ 夜间**自动合并**(新并旧+别名登记+图节点合一),写审计日志。
   注册表 note-codes.json 按**身份键**登记(identity-first),不按字面。
- **模板**(三段式,frontmatter `type: concept-auto` + `book` + `status: auto|audited|user-edited`):
  `## 定义`(逐字引文 blockquote + 页锚 `![[book.pdf#page=N]]`;AI 生成则标"AI 生成,仅参考")/
  `## 概念链接(自动)`(每边一行:`- 前置:[[衛生管理]] — 理由(证据 p12)`;**整区机器重写**,区外用户内容永久保留,
  同 ankicards 区块管理模式)/ `## AI 解释(自动)`(可关)。
- **挂起边=未解析 wikilink**(Obsidian 原生灰显,零实现);**Graph View 免费镜像概念网**。
- 机器真相仍在 `emergent-graph.json`(skilltree/统一图消费);笔记是人类可读镜像,单向 机器→笔记「自动区」同步。
- `promote_concepts.collect_seeds` 扩展:除 NOTE_PATTERN 外,收 `资源/概念/**/*.md`(frontmatter type=concept-auto)。

## 4. AI 定期审计(代替人工逐条确认)

- 夜间任务(off-peak,套 budget 配额):抽查**新边 + tier2/散文边 + 被诊断数据反证的边**,
  重读证据句(±1 句),站不住 → 降级 related 或摘除,写 `state/attention/edge-audit-log.jsonl`(谁/何时/为何降)。
- 边状态机:`auto`(生成即生效,小角标)→ `audited`(审计过)→ 摘除(留墓碑可查)。
- 用户随手纠错入口**保留但可选**(unified 页确认/否决端点转为 override:用户改过的边审计不再动)。
- **掌握度确认铁律不变**:mastery 变更仍必须 用户确认(§边放开 ≠ §掌握度放开)。

## 5. 方向与环 / 数据结构

- 方向:主流程=前文词→主体词(书序);存量扫描=被写进定义者→引用者。AI 只降级不反向。
- 环:拓扑排序,剔证据最弱一条重跑;传递归约仅在两段边都 `audited` 后把直连标 `shadowed`(不删)。
- 边:`{from,to,kind:prereq|related,origin:"emergent",status:"auto|audited|removed",method,quote,quote_src,
  src_tier:"book|quote|prose",strength,ver:3}`;审计日志 jsonl;AI 关系/定义调用按 (词,text_sha8,ver) 缓存。

## 6. 施工顺序

| 步 | 内容 | AI |
|---|---|---|
