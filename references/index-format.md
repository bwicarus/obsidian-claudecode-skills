# 知识索引格式规范

## 文件位置
`C:\obsidian\claude\index\knowledge-index.md`

## 整体结构
```
# 知识索引

## <一级科目>
### <二级分支>
- [[文件名]] `关键词1, 关键词2, 关键词3` — 摘要（不超过60字）
```

## 单条目格式
```
- [[文件名]] `关键词, 关键词, 关键词` — 摘要内容
```

**各字段说明：**
- `[[文件名]]`：Obsidian wikilink，不带 `.md` 扩展名
- 反引号内：3-8 个关键词，逗号+空格分隔
- ` — `：空格 + 破折号 + 空格（分隔关键词与摘要）
- 摘要：1-2 句话，说明核心知识点，不超过 60 字

## 排列规则
- 同一二级分支内按拼音/字母顺序排列
- 新条目插入对应分支的末尾，再由用户或后续操作整理顺序
- 一级科目、二级分支标题用 `##` / `###`，不用更深的层级

## 写入规则
- 对应分支不存在时，先在正确位置创建 `### 分支名` 标题
- 已有同名 `[[文件名]]` 条目时，更新该条目而非重复插入
- 空分支节（无条目）保留标题，不删除

## 完整示例
```markdown
## 数学
### 线性代数
- [[000-向量空间]] `向量空间, 线性组合, 基, 维度` — 定义向量空间的八条公理及子空间的判断方法
- [[逆矩阵]] `逆矩阵, 行列式, 可逆性` — 逆矩阵的存在条件、唯一性及计算方式

### 微积分
- [[夹逼定理]] `极限, 夹逼定理, 收敛` — 利用上下界函数确定极限值的方法，常用于三角函数极限

## 物理
### 光学
- [[光的色散_学习手册_v1.0]] `色散, 折射率, 棱镜, 光谱` — 白光经棱镜分解为各色光的原理及折射率与波长的关系
```
