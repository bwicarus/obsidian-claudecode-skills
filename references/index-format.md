# 知识索引格式规范

## 文件结构
- `index/knowledge-index.md` — 入口文件，只列出各科目及条目数汇总，不含具体条目
- `index/{科目}.md` — 各科目条目文件，包含该科目所有分支和具体条目
- `index/{科目}/{分支}.md` — 分支拆分文件（某分支条目超 30 条时自动创建）

**读写时始终操作 `index/{科目}.md`（或拆分后的分支文件），不要读写 `knowledge-index.md` 的条目内容。**

## 条目格式
```
- [[文件名]] `关键词1, 关键词2, 关键词3` — 摘要（不超过60字）
```

**各字段说明：**
- `[[文件名]]`：Obsidian wikilink，不带 `.md` 扩展名
- 反引号内：3-8 个关键词，逗号+空格分隔
- ` — `：空格 + 破折号 + 空格（分隔关键词与摘要）
- 摘要：1-2 句话，说明核心知识点，不超过 60 字

## 科目文件结构
```markdown
# 数学索引

### 线性代数
- [[000-向量空间]] `向量空间, 线性组合, 基, 维度` — 定义向量空间的八条公理及子空间的判断方法
- [[000-Fn]] `Fⁿ, 坐标, 向量加法` — 定义F上的n维向量空间Fⁿ

### 微积分
- [[夹逼定理]] `极限, 夹逼定理, 收敛` — 利用上下界函数确定极限值的方法
```

## 写入规则
- 对应分支不存在时，先在正确位置创建 `### 分支名` 标题
- 已有同名 `[[文件名]]` 条目时，更新该条目而非重复插入
- 新条目插入对应分支末尾
