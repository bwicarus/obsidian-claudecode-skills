## 5. 出问题先看哪

| 现象 | 先看 |
|---|---|
| iPad 旁听 / 降噪 / 时间轴任何问题 | App 设置 →「旁听与降噪」→ 日志（同时送 client-log，`surface=native-ambient`） |
| 服务端判断 / 人物 / 时间轴 | `~/BW/data/…/state/ambient/log.jsonl`（按 `CLAUDE_PROJECT` 解析）、`~/BW/logs/webapp*.log` |
| iPad 报 403 而 webapp 日志里没有对应请求 | `lsof -nP -iTCP:<端口> -sTCP:LISTEN`（隔空播放接收器那一坑） |
| App 端通用报错 | `state/reader-client-log/<user>.jsonl` |

⚠ macOS 自带 grep 不认 `\|`，用 `grep -E "a|b"`；`tailscale` 命令在 `/Applications/Tailscale.app/Contents/MacOS/Tailscale`。
