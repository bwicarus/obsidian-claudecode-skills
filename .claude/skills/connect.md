# Skill: connect

通过知识索引查找与目标笔记相关的其他笔记，并在目标笔记末尾追加 Obsidian 格式链接。

## 触发方式
用户输入 `/connect` 并提供目标文件路径或文件名。

## 执行步骤

1. **读取目标文件**
   读取用户指定的笔记，提取其主要概念和关键词。

2. **分级检索知识索引**
   读取 `index/knowledge-index.md`，按优先级查找相关条目：
   - 优先：同一二级分支下关键词重叠的笔记
   - 其次：同一一级科目下概念相关的笔记
   - 匹配标准：关键词重叠、概念互补、存在依赖或对比关系

3. **筛选关联笔记**
   选出相关度较高的笔记（通常 2-6 个），排除目标文件自身。
   每条保留简短的关联原因（不超过 20 字）。

4. **追加链接到原文**
   调用脚本写入（自动处理新增 / 更新已有节）：
   ```
   C:\Users\bwica\AppData\Local\Programs\Python\Python313\python.exe C:\obsidian\claude\scripts\connect_note.py --note "<笔记完整路径>" --link "文件名1|关联原因" --link "文件名2|关联原因"
   ```
   每个 `--link` 传一条，原因不超过 20 字，文件名不带扩展名。

5. **汇报结果**
   告知用户找到了哪些关联笔记及脚本输出结果。
