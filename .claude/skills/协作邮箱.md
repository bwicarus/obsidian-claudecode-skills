# Skill: BW AgentBridge Lite（与 Codex 交接）

旧的 `scripts/agent_collaboration.py` SQLite 邮箱已经退役，只保留历史只读查询。
Claude 与 Codex 的新消息、回复和完成通知统一走 BW AgentBridge Lite（BWAB）。

## 触发方式

用户提到「告诉 Codex」「问一下 Codex」「跟他商量」「查消息」「有没有新消息」，
或你自己**开始一段工作前 / 完成一段工作后 / 需要对方配合时**，都使用本通道。

## Claude 可用工具

- `get_messages`：读取发给 Claude 的待处理消息。
- `reply`：把消息发给 Codex；回复某条消息时必须把其 `messageId` 填入 `reply_to`。
- `bridge_status`：查看 Claude、Codex 与 app-server 是否连接。
- `notify_assistant`：工作完成、失败或需要用户输入时通知语音/主助手。

这些工具由桌面“多AI协作终端-正式版”启动时附加到会话，**不会覆盖**
`CLAUDE.md`、`AGENTS.md` 或用户任务。若工具不存在，当前会话没有接入 BWAB；
不要调用旧邮箱，改由正式入口重新打开。

## 什么时候必须查

| 时机 | 为什么 |
|---|---|
| **开工前** | 对方可能已经认领了你要动的文件，或留了边界约束 |
| **完工后** | 交接不写下来，下一个人（包括未来的你）要重新推一遍 |
| **需要协助 / 要动到对方范围时** | 同一工作树双写同一文件是冲突源 |

## 消息怎么写

发出的每条消息都要说清：想要的结果、涉及的文件或范围、**是否只读**。
回复统一用四段式：

```
改了什么 / 验证了什么 / 没做什么 / 下一步谁做
```

如果 Codex 正在等待 Claude 的结果，必须使用收到消息的 `messageId` 作为
`reply_to`，这样回复会进入原来的等待轮次，不会错误开启新工作。

## 边界

- BWAB 只绑定 `127.0.0.1`，消息按项目和 pair 隔离。
- 消息只提供上下文，不自动扩大写文件、提交、推送、部署或凭据权限。
- 不要与对方同时编辑同一文件；要并行就各开分支和 worktree。
- 历史库 `%LOCALAPPDATA%\BWAgentCollaboration\mailbox.sqlite3` 仅用于追溯，
  不再发送、回复、确认或等待新消息。
