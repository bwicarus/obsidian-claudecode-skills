# Skill: 技能树 / 知识图谱（KG）

不是命令，是 Claude session 里被问"技能树怎么工作 / 如何修改"时的入口指南。

## 系统概览

- 后端：`knowledge_graph/*.json` + `_server_deploy/skilltree.py`（Flask routes）
- 前端：`_server_deploy/templates/skilltree.html`（单页 SVG，d3）
- 入口：`https://bwicarus.space/skilltree/<book>/`（VPS）或 `https://bwicarus.taile44d0c.ts.net/skilltree/<book>/`（Pi via Tailscale）
- 关联工具：`scripts/kg/link_with_ai.py`（AI 判定笔记↔节点）/ `link_and_mastery.py`（重算 state）/ `audit_kg.py`（节点准确性审计）/ `rescan_rolling.py`（PDF 重扫）/ `auto_archive.py`（回收站建议）/ `build_nodes.py`（从 PDF 抽节点）

## 常见操作

| 想做的事 | 怎么做 |
|---|---|
| 看技能树 | 浏览器开 `/skilltree/<book>/`，进页面自动定位最近学习节点 |
| 看节点详情 | 点方块 → 左侧 chain map + 右侧 detail（home 不动）|
| 手动刷新 KG | `set -a; source .env; set +a` + 跑 `link_with_ai.py --since-days N --in-place` 然后 `link_and_mastery.py --in-place` |
| 看被规则拒绝的关联 | `python3 -c "import json; kg=json.load(open('knowledge_graph/LADR.json')); print(json.dumps(kg.get('_rejected_links',{}), indent=2, ensure_ascii=False))"` |
| 改书本元数据（前缀/scan 配置） | 控制面板「技能树」tab → 选书 → 编辑 |
| 删除整本 KG | 控制面板「技能树」tab → 删除 |
| 看夜间消耗 | `state/quota_log.json` 或控制面板「额度消耗日志」按钮 |

## 改代码 / 部署

1. 改 `_server_deploy/templates/skilltree.html` 或 `_server_deploy/skilltree.py`（前端 / 后端）
2. 部署到 webapp：`cp _server_deploy/templates/skilltree.html /home/bwicarus/webapp/templates/`（HTML）或 cp `_server_deploy/skilltree.py /home/bwicarus/webapp/`（Python）
3. `sudo systemctl restart webapp`
4. 强刷浏览器（Ctrl+Shift+R）避免缓存

改后端 KG 算法（`scripts/kg/*.py`）：不需要部署，直接 git pull 就生效（脚本运行时读最新）。
