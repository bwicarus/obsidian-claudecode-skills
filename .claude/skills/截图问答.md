# Skill: 截图问答 / QA Browser

不是命令，是 Claude session 里被问 QA 系统时的入口指南。

## 系统概览

- 源码：`_client/core/qa_browser.py`（HTML/JS 内嵌 + Python 路由）
- 服务器：systemd `qa-server.service` 跑 :9091 daemon + :9090 cmd_server
- 本机：`ctrl+shift+q` 临时启进程
- iPad：通过 Tailscale 直连 `http://<Tailscale-IP>:9091/`（不经公网）

## 两种使用模式

1. **普通对话**（默认）：截图 / 粘贴图 → 问 → AI 答；可勾选 AI 回答里的内容**创建新笔记**（2026-05-26 加）
2. **cardCtx**（Anki 卡复习链接进入）：URL `?card=<local_id>`；可勾选 AI 回答**改进卡片或源笔记**

## 改代码 / 部署（服务器 Pi 侧）

1. 改 `_client/core/qa_browser.py`
2. 重启：`sudo systemctl restart qa-server`
3. 验证：`systemctl is-active qa-server` + `curl http://localhost:9091/`
4. iPad 端 / 浏览器强刷

注：qa-server.service `ExecStartPre` 有 3 个 sed patch（CDN URL / 权限 / allowedTools），git pull 覆盖后 restart 时自动重新应用。

## 关键 API（do_POST in qa_browser.py）

- `/api/chat` SSE 流式对话（Accept: text/event-stream 触发）
- `/api/create-note` 创建新笔记（普通模式专用）— 已 job 化：立即返回 `job_id`，复用 `_card_jobs` + `/api/card-update-status?job=<job_id>` 轮询（AI 整理 10-30s，移动端连接易断）
- `/api/card-update` 卡片 / 笔记改进（cardCtx 模式，同样 async job_id 模式）
- `/api/card-delete` 删除卡片（AnkiWeb sync 后台化，先回 `synced:'pending'`）
- `/api/inject-image` iPad 远程注入截图
- `/api/save` / `/api/discard` 保存对话到 vault / 弃稿。server 模式下 save 也返回 `job_id` 供轮询（classify 是同步 AI 调用可达数十秒，先快照会话再 reset 继续服务）
