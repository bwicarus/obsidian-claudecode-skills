# Skill: 登记新笔记

对指定笔记执行完整的登记流程：PDF 标注 → 摘要索引 → 关联链接。

## 触发方式
用户输入 `/登记新笔记` 并提供笔记路径或文件名。

## 执行步骤

### 第一步：PDF 标注
```
python C:\obsidian\claude\scripts\annotate_note.py --note "<笔记完整路径>"
```
脚本扫描笔记中所有 `![[*.pdf#...]]` 链接，在每个链接下方插入 `> [!quote] 原文` 块。
已有 callout 的链接自动跳过。输出每个链接的处理状态。

### 第二步：读取清理后的笔记内容
```
python C:\obsidian\claude\scripts\summarize_note.py --read "<笔记完整路径>"
```

### 第三步：分析内容，仅输出以下三行
```
KEYWORDS: 关键词1, 关键词2, 关键词3
SUMMARY: 一句话摘要（不超过60字）
CATEGORY: 一级科目/二级分支
```
- KEYWORDS：3-8 个核心概念词，逗号分隔
- SUMMARY：说明核心知识点，不超过 60 字
- CATEGORY：从 `references/vault-structure.md` 中选择，格式如 `数学/线性代数`
- **不要输出其他任何内容**

### 第四步：写入知识索引
```
python C:\obsidian\claude\scripts\summarize_note.py --write "<笔记完整路径>" --keywords "关键词1, 关键词2" --summary "摘要内容" --category "数学/线性代数"
```

### 第五步：查找关联笔记
读取对应科目索引文件（`index/{科目}.md`，若已拆分则读取对应分支文件），
找出关键词重叠或概念互补的条目（2-6 个），排除目标文件自身。

### 第六步：追加关联链接
在目标笔记末尾追加（如已有 `## 相关笔记` 节则更新而非重复添加）：

```markdown

---
## 相关笔记
- [[文件名]] — 关联原因（不超过20字）
```

### 第七步：判断是否制卡
读取 `references/anki-selection-rules.md`，根据第二步已读取的笔记内容判断是否值得制卡。

**若值得制卡：**
读取 `references/anki-card-format.md`，生成卡片 JSON，写入临时文件：
`C:\obsidian\claude\anki\tmp_cards.json`

然后同步：
```
C:\Users\bwica\AppData\Local\Programs\Python\Python313\python.exe C:\obsidian\claude\scripts\anki_from_note.py --sync "<笔记完整路径>" --cards-json "C:\obsidian\claude\anki\tmp_cards.json"
```
同步完成后删除临时文件。

**若不值得制卡：**
```
C:\Users\bwica\AppData\Local\Programs\Python\Python313\python.exe C:\obsidian\claude\scripts\anki_from_note.py --sync "<笔记完整路径>" --no-cards-reason "<原因>"
```

### 第八步：汇报结果
告知用户：
- PDF 标注处理了几个链接（跳过了几个）
- 索引写入结果（新增 / 更新）
- 追加了哪些关联笔记
- 制卡结果（同步了几张 / 无需制卡原因）
