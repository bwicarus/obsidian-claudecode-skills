# 摄像头：看一眼现实世界

用户家里接着实体摄像头。要看现场时调 `reader_camera_snap`，它**当场拍一张**
并把照片直接给你。

    reader_camera_snap  {}                  // 默认那台
    reader_camera_snap  { "cameraId": "pi" } // 指定某台

约两秒。回复是两段：一段 JSON 元数据（亮度、尺寸、拍摄时刻），一段图片。

## 什么时候调

- 用户问「现在……怎么样了」「你看看……」这类**只有看一眼才能回答**的问题。
- 你自己需要现场依据时（例如用户说「我出门前把东西放门口了」，你要核实）。

**不要**为了寒暄或凑上下文而拍。这是用户家里的实时画面，每一次调用都是一次
拍摄；调了就要说清你为什么要看。

## ⚠ 摄像头不在快照里

快照里**没有**摄像头画面，将来也不会有（用户 2026-08-27 定的）。所以：

- 别在快照里找 `camera` 字段，那里不会有。
- 你手上的不是「一直开着的监控」，是「你按一下才拍一张」。
  想知道现在怎么样，就得调一次。

## 摄像头是通用的，不绑定任何场景

镜头对着哪儿就拍到哪儿，位置会变。**先看图，再说话** —— 不要因为用户以前
提过某件事，就假设画面里一定有它。画面里没有的东西，就说没看到。

## 怎么读那段元数据

- `brightness` 是整幅画面的平均灰度（0-255）。**低于 35 基本就是黑的**：
  这时要说「太暗了看不清」，而不是硬猜画面里有什么。说看不清是正确回答。
- `width`/`height` 是实际尺寸。
- `capturedAtUtcMs` 是拍摄时刻 —— 就是刚刚，不是缓存。

## 失败了怎么办

失败会带 `code` 和一句中文原因，**原样转告用户**，别自己编：

| code | 意思 | 跟用户怎么说 |
|---|---|---|
| `BW_CAMERA_TIMEOUT` | 摄像头那台机器没反应 | 摄像头所在的机器可能关了或断网了 |
| `BW_CAMERA_FAILED` | 那台机器给了具体原因 | 把 message 里的原话转达 |
| `BW_CAMERA_NOT_INSTALLED` | 这台电脑上没装取图组件 | 桌面端还没部署过 |
| `BW_CAMERA_BAD_ID` | 摄像头名写错了 | 换个名字，或问用户有哪几台 |

⚠ **拍不到 ≠ 画面里没有那个东西**。这两件事该说的话完全不同：
前者是「我看不到」，后者是「我看了，没有」。别把前者说成后者。

## 现在还没有的

切分辨率、转云台、开补光 —— 用户说以后会加。**现在没有**，别声称能做。
