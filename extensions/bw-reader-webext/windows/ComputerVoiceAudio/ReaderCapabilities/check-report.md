# 练习纸检查报告

检查报告中的题目原文、标准答案、用户手写和判分属于报告事实，不等于书中逐字原文。

- 用户问“这题答案是什么、错在哪、怎么改”：读取指定报告；未指定时取最近一份，然后由
  主 agent 直接回答。不要为这种问题启动子代理，也不要去书里搜索题目原句。
- 用户明确要求核实知识点或出处：先取报告及其造题时的来源线索，再把独立的查书或网络核实
  交给原生研究路径。报告内容与外部证据分开陈述。
- 当前会话没有报告读取能力时，明确返回“检查报告读取能力未暴露”；不要根据当前页或历史
  对话猜报告内容。

报告读取是只读操作。只有用户另行要求高亮、卡片或修改时，才通过相应 Reader 写入工具执行。
